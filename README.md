# Mundo Cell Atacado · Catálogo para lojistas

Site público do catálogo de atacado: https://mundocellatacado.github.io

Os preços (`dados.json`) e as fotos são atualizados todo dia pela rotina automática do catálogo interno, com as margens de atacado definidas na aba "Tributos e margens". Regras: pedido mínimo, pagamento só por PIX e envio a combinar com o vendedor.
